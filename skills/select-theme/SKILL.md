# Select Theme Skill

## Purpose

Help the user choose a visual theme for their presentation, allow customization of any token, and produce a finalized CSS variable block that all `design-slide` instances will consume.

## Available Themes

All themes are located at `CLAUDE_PLUGIN_ROOT/themes/`. Each theme is a directory containing:

- `theme.json` — metadata and CSS variable definitions
- `preview.png` — thumbnail for visual preview
- `README.md` — description of intended use and tone

### Theme Catalogue

Present the following themes to the user (load actual names and descriptions from `CLAUDE_PLUGIN_ROOT/themes/`):

| Theme ID | Tone | Best For |
|---|---|---|
| `midnight-bold` | Dark, dramatic | Tech startups, product launches |
| `clean-light` | Minimal, airy | Corporate, consulting, finance |
| `editorial-ink` | High contrast, typographic | Thought leadership, publishing |
| `warm-earth` | Organic, textured | Sustainability, brand storytelling |
| `neon-future` | Vibrant, electric | Creative agencies, gaming |
| `executive-navy` | Formal, authoritative | Board presentations, investor decks |
| `pastel-soft` | Gentle, approachable | Education, HR, wellness |
| `monochrome-grid` | Structured, Swiss | Architecture, design portfolios |
| `gradient-glow` | Dynamic, modern | SaaS, marketing campaigns |
| `paper-craft` | Tactile, artisanal | Indie brands, lifestyle |

If `CLAUDE_PLUGIN_ROOT/themes/` contains additional themes not listed above, include them in the presentation.

## Selection Process

### 1. Ask About Context (if not already known)

If the user has not specified a theme or provided enough context, ask:

- "What is the tone of this presentation — professional/formal, creative/bold, or friendly/approachable?"
- "Does your organization have a primary brand color I should start from?"
- "Is this for internal use or an external audience (clients, investors, public)?"

### 2. Recommend Top 3 Themes

Based on the user's input and presentation topic, recommend 3 themes with a brief rationale for each. If possible, reference the preview image path so the user can view thumbnails.

Example recommendation format:

```
1. midnight-bold — Strong visual impact, great for a product launch narrative.
   Preview: CLAUDE_PLUGIN_ROOT/themes/midnight-bold/preview.png

2. clean-light — Universally readable, professional tone.
   Preview: CLAUDE_PLUGIN_ROOT/themes/clean-light/preview.png

3. editorial-ink — Typography-forward, suits thought leadership content.
   Preview: CLAUDE_PLUGIN_ROOT/themes/editorial-ink/preview.png
```

### 3. Confirm Selection

Ask the user to confirm their choice or pick from the full catalogue.

## Customization

After loading the base theme, offer the user the opportunity to customize individual tokens:

### Common Customizations

- **Primary accent color** — "Would you like to adjust the accent color? For example, to match your brand."
- **Font pairing** — "The default heading font is [X]. Would you prefer a different typeface?"
- **Background tone** — "The background is [dark/light]. Would you like to flip to the opposite?"

### Applying Brand Profile Overrides

If a `brand-profile.json` has been generated by the `brand-profile` skill, automatically override the following tokens with brand values (user confirmation not required, but inform the user):

| Brand profile field | CSS variable overridden |
|---|---|
| `primary_color` | `--color-primary`, `--color-accent` |
| `secondary_color` | `--color-surface` |
| `heading_font` | `--font-heading` |
| `body_font` | `--font-body` |
| `logo_url` | `--logo-url` (custom token) |

### Theme Preview Support

If the environment supports image display, show `CLAUDE_PLUGIN_ROOT/themes/<theme-id>/preview.png` when presenting options.

If it does not, describe the theme's visual character in 2–3 sentences using the `description` field from `theme.json`.

## Output Format: Resolved CSS Variable Block

After selection and any customization, produce the final resolved block:

```css
/* Theme: midnight-bold | Generated by select-theme skill */
:root {
  --color-background: #0d0d1a;
  --color-primary: #1a1a2e;
  --color-accent: #e94560;
  --color-surface: #16213e;
  --color-text: #eaeaea;
  --color-text-muted: #888ba0;
  --font-heading: 'Playfair Display', Georgia, serif;
  --font-body: 'Inter', system-ui, sans-serif;
  --font-mono: 'Fira Code', monospace;
  --font-size-base: 18px;
  --font-size-heading-xl: clamp(2.5rem, 5vw, 5rem);
  --font-size-heading-lg: clamp(2rem, 3.5vw, 3.5rem);
  --font-size-heading-md: clamp(1.5rem, 2.5vw, 2.5rem);
  --font-size-body: clamp(1rem, 1.5vw, 1.25rem);
  --spacing-base: 32px;
  --spacing-tight: 16px;
  --spacing-loose: 64px;
  --radius-card: 8px;
  --radius-button: 4px;
  --shadow-card: 0 4px 24px rgba(0,0,0,0.4);
  --transition-base: 200ms ease;
}
```

Also return a structured metadata object for use by other skills:

```json
{
  "theme_id": "midnight-bold",
  "theme_name": "Midnight Bold",
  "google_fonts": ["Playfair Display:wght@700;900", "Inter:wght@400;500;600"],
  "customizations_applied": [],
  "brand_overrides_applied": ["--color-accent", "--font-heading"],
  "css_variables": { /* full key-value map */ }
}
```

Pass both the CSS block and the metadata object to `plan-slides`, `design-slide`, and `playground`.
